## User, problem, promise
- Target: Sui dApp / protocol engineers and ecosystem support responders, starting with one operator-managed shared case space.
- Problem: an onchain execution failure can be investigated, but the human-confirmed cause and fix are scattered. Future engineers start from scratch.
- Promise: retain a verifiable evidence-linked resolution and reuse it safely when a compatible onchain failure recurs.
- Insight: Chain records **what failed**; the memory layer remembers **what worked to resolve it**.

## Primary workflow
1. Import a real Sui transaction digest.
2. Tatum Sui Mainnet gRPC fetches transaction status/effects; show immutable digest and source.
3. If onchain failure, normalize error class with error text, package identifier when available, network and operator-supplied SDK/package version; do not hallucinate package from arbitrary text.
4. Walrus semantic recall finds candidate past cases; deterministic guards require network/error class and version/package where both were known. Ambiguity -> investigate, not 'resolved'.
5. Engineer records a resolution with a specific confirmation method and proof link, actively approves it for knowledge reuse; unconfirmed notes are NOT counted as verified fixes.
6. Walrus stores a sanitized structured memory; completion only after async remember job returns Mainnet blob ID. UI shows explicit state.
7. A later compatible failure retrieves a matching reviewed case. Product shows suggested procedure + original evidence + uncertainty, with human final authority.

## Magic moment
Second distinct real failure -> eligible stored confirmed case -> 'previously verified resolution' appears with source and concrete rationale. A mismatching failure produces NO confident recommendation. Remove memory -> result reverts to no recommendation.

## P0 features
- Read-only digest lookup via Tatum gRPC, actual source/provenance.
- Failure/success/unknown distinction; no submission or signing.
- Submit human-confirmed case and completion receipt with blob ID.
- Walrus recall with transparent candidate filtering and exact/mismatch reasoning.
- Saved-case count of completed real Mainnet writes, not generated counter.
- Workspace states: empty, no keys, loading, live, failed/missing, results.
- Landing and app/workspace as separate routes.
- Secure server-only key storage. No public anonymous write access in production without admin protection.

## Non-goals / hard stops
- No generic blockchain explorer, one-off AI explanation product, generalized autonomous incident management.
- No auto-executing fixes, funds movement, wallet signing, malware/security 'safe' labels, unrestricted sharing of user tickets or secrets.
- No claim every failure has a uniquely identifiable cause; no certainty based only on one error substring.
- No 10 fake memories or fabricated Mainnet receipts.
- No incident classification of transport failures as completed onchain transactions.
- Do not expand to Indexer Recovery or multiple chains during this hackathon.

## Fundamental assumptions / kill gates

- Walrus Mainnet account+delegated key, remember completion + recall works (UNPROVEN).
- At least two genuine comparable failed digests plus engineer-verified fix or credible proof procedure are available (UNPROVEN).
- Track fit for developer-workflow agent is accepted by organizer (UNCERTAIN).
- At least one external developer validates real utility (UNPROVEN).
- If these fail, do not silently turn the product into a simulation or an AI error explainer. Escalate to operator for thesis review.

## Data model, minimal
```
IncidentCase {
  schema: 'incident-memory/v1',
  caseId, digest, network, executionFailed, errorKind, errorSummary,
  packageId?, packageVersion?, sdkVersion?,
  diagnosis, resolutionSteps, evidenceUrl, verifier, verifiedAt,
  status: 'verified', sanitized: true
}
```
Human confirmation is an affirmative action, not a claim generated by model.
Each stored memory is a JSON string containing a readable explanation + structured fields; use parser/validator for recalled text and never run arbitrary code returned by memory.
