# Rouse brand assets — 1.0

Product: evidence-backed memory for recurring Sui transaction failures.
Name locked by the user. This asset family was selected through internal concept exploration and rendered review; it does not imply user visual signoff.

## Concept

Retained counter: an open lowercase r with a stepped shoulder cut. The opening stays visible at small sizes and connects the icon to the custom first letter in the wordmark. Use one canonical geometry across touchpoints.

## Files

- mark.svg / wordmark.svg: foreground-inheriting vector masters (currentColor).
- mark-dark.svg / wordmark-dark.svg: dark ink for light backgrounds.
- mark-light.svg / wordmark-light.svg: light ink for dark backgrounds.
- Corresponding PNGs: 512px marks; 660×144 wordmarks.
- favicon.svg plus favicon-16.png / favicon-32.png: dedicated graphite/lime icon.
- avatar.svg / avatar.png: 512×512 square avatar, inset for circular crops.
- social-card.png: 1200×630 Open Graph / repository cover.
- social-preview.html: editable source for the social export.
- index.html: responsive brand board and application specimen.
- tokens.json: palette, dimensions and type roles.
- fonts/: self-hosted, unmodified Space Grotesk, DM Sans and DM Mono with family license files. The logo SVGs use paths and do not require a font.

## Usage

Minimum standalone mark 16px; prefer 24px. Minimum wordmark 104px wide. Clear space at least one-quarter of the mark's height. Do not stretch, rotate, add a glow/gradient, or replace the wordmark with live text.

Palette roles: ink #0e1212; surface #17201c; paper #f5f5ef; recalled evidence/action #c8ed9b; failed execution #ef8b6e; muted #a1aaa5; line #34403d. Color never replaces status text.

Heading: Space Grotesk. Body: DM Sans. Provenance: DM Mono. The wordmark uses a custom first r with outlined Archivo Black letters. Archivo Black source/license is retained under evidence/brand-rouse/ in the repository and FONT-LICENSE.txt in the downloadable kit.

Keep observed failures, simulation-tested procedures and human-reviewed resolutions distinct. No automatically-fixed claim. Tatum and Walrus may appear as supporting technology names, separate from the Rouse mark.

The board is a brand specimen, not a screenshot of the deployed app. Current live product migration is a separate implementation/release step. Preserve historical Casewake records and immutable proof links.
