# BRAND — CASEWAKE

Version: 1.0 / 2026-11-04. Hackathon product identity. Final trademark clearance NOT completed.

## Naming decision
**CASEWAKE** / pronounced KAYS-wayk.

Meaning: when a new failure repeats the shape of an old case, the old evidence *wakes* and becomes useful to the next engineer.

Descriptor: *Evidence-backed memory for recurring Sui transaction failures.*

Positioning: "The next failure shouldn't start from zero."

Product-specific differentiator: distinguishes (1) immutable chain-observed evidence, (2) a repeatable simulation-tested troubleshooting pattern and (3) an independently human-verified historical fix. Never promote one tier to another.

Naming territory evaluation:
- **ReTrace / Retrace**: rejected; competing incident-management product exists and crowded diagnostic language.
- **Tracekin**: rejected; used by another application unrelated to this sector, but weak category distinction.
- **Aftercase**: flexible but vague and closer to postmortem documentation.
- **Casewake**: chosen; directly encodes recurrent case resurfacing. Preliminary web exact-word search showed no obvious existing developer software with the same product name. Fandom / personal unrelated uses exist. NOT legal clearance and domain availability not confirmed. Recheck before commercial launch.

## Voice and vocabulary
- Evidence first. Technical but legible. Steady, exact, humane.
- Preferred: "observed", "simulation-tested", "eligible for review", "historical repair not verified", "completed memory write".
- Forbidden: "automatically fixed", "verified fix" for test simulations, "AI solved your transaction", fabricated saved time.
- Tagline: **The next failure shouldn't start from zero.**

## Visual idea
Two distinct incident marks converge on a shared recovered precedent. Make that visible as **offset brackets with a continuous middle span**, not a chain, shield, circuit, hexagon, robot, neural dot, or generic geometric crypto icon.

3 identity territories assessed:
1. **Evidence notebook:** warm ivory paper, red pencil editorial marks, serif headings. Strong trust, but risks looking like a legal document instead of a functional Sui devtool.
2. **Trace instrument:** near-black metal, acid-lime evidence line, oxidized-orange error state, mono provenance + pragmatic sans. Adopt and refine existing implemented UI. The line is the repeat-detection motif, not meaningless glowing crypto decoration.
3. **Quiet workshop:** graphite/stone neutral, ochre support notes, confident type. Inviting but insufficiently distinct from generalized developer tooling.

Chosen: Trace instrument / controlled fracture. Preserve the existing app hierarchy; replace the generic rotated diamond icon with two misaligned evidence brackets and a binding rule. No gradient, no chain-link symbolism.

## Hackathon Operator NAME_LOCK adversarial completion — November 6, 2026

**Lock retained: CASEWAKE.** The existing accepted product identity and Casewake wordmark remain unchanged; this is an audit of the decision, not a new naming vote.

Naming brief: short, pronounceable name for a *remembered, human-verified engineering case*; not an explorer, autonomous repair bot, DeFi strategy, or generic AI dashboard. Product category: developer incident intelligence / reviewed resolution memory. Pronunciation: KAYS-wayk.

Candidate territories and attack (considered, not proposed renames):
